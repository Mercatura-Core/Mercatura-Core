# Mercatura Core Pre-Release Status

Mercatura Core is currently in pre-release development.

No official production Mercatura Core release is published from this repository
yet.

The source tree is under active development and validation. Official release
binaries and finalized public-network launch parameters will be published only
after the required testing and release process is complete.

## Current Development Status

Current Mercatura-specific development includes:

- pure proof-of-work consensus
- MercaHash proof-of-work
- Mercatura-specific network identity and timing
- SP-LT adaptive monetary policy
- native witness-v2 ML-DSA-65 post-quantum ownership authorization
- Mercatura Core Qt wallet integration
- Mercatura PSBT integration
- Mercatura-specific block-cap, wallet, and validation behavior

Development status does not constitute a production release.

Current development and test-network parameters may change before public
network launch.

## Binaries

Locally produced development builds are not official Mercatura releases.

Official binaries, release hashes, installation guidance, and release notes
will be published through the formal Mercatura release process.

## Network Parameters

Finalized genesis and public-network identity parameters will be explicitly
documented with the corresponding network release.

Development and test parameters may change before that point.

## Bug Reports

Reproducible technical bugs may be reported through the Mercatura GitHub issue
tracker.

Security-sensitive issues must not be disclosed publicly. Follow the repository
[Security Policy](/SECURITY.md).

## Upstream Historical Notes

The `doc/release-notes/` directory contains historical upstream Bitcoin Core
release-note material retained for implementation history and provenance.

Those files are not Mercatura release announcements.
