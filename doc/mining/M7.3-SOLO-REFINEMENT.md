# M7.3 Solo Mining refinement

Baseline: `9252a831ede29ffb69d8618daf97950fd0d0023a` (M7.2). The conventional
pool coordinator, Qt transport, mode/settings/UI, continuous-share scheduling,
fixtures and pool-only application dependencies are removed. Qt Network remains
for the existing payment-URI local IPC; pool TLS plugin requirements are removed. Historical M7.2 source and
qualification remain recoverable through Git. Standard mining RPCs remain.

The Solo page retains its hardware form, statistics, scroll area and Start/Stop
buttons. CPU workers are manual and persistent, with all usable logical processors
and the existing memory/affinity safeguards. Counter-based 10-second/60-second
averages, session hashes/average and monotonic runtime are added. A palette-colored
pickaxe replaces the home icon in creation and refresh paths. Copy and receiving
address-book selection make the automatic owned PQ reward destination discoverable
without changing signing or maturity.

## Build and test gates

Expected fresh build: 15–45 minutes at `-j4`; focused gates: 2–10 minutes;
complete Mercatura-native suite: 10–35 minutes at `--jobs=4`.

```sh
cmake -S . -B work/build-m73 -G Ninja -DCMAKE_BUILD_TYPE=Release \
  -DBUILD_GUI=ON -DBUILD_TESTS=ON -DENABLE_IPC=OFF \
  -DWITH_ZMQ=OFF -DWITH_DBUS=OFF -DWITH_QRENCODE=OFF \
  -DWITH_OPENCL_MINING=ON -DMERCATURA_PUBLIC_TESTNET_RELEASE=OFF
cmake --build work/build-m73 -j4 --target bitcoin-qt bitcoind bitcoin-cli \
  test_bitcoin test_mining-qt mercatura-gpu-check mining-bench
work/build-m73/bin/test_bitcoin \
  --run_test=cpu_miner_tests,mining_statistics_tests,gpu_miner_tests,mercahash_gpu_tests,mercahash_gpu_sync_tests,mining_tests_wallet,mining_tests_solo,mercatura_emission_tests,mercatura_fixedpoint_tests,mercatura_controller_tests,pow_tests
work/build-m73/bin/test_bitcoin --run_test=crypto_tests/mercahash_v1_vectors
QT_QPA_PLATFORM=offscreen work/build-m73/bin/test_mining-qt
QT_QPA_PLATFORM=offscreen QT_SCALE_FACTOR=2 work/build-m73/bin/test_mining-qt
python3 work/build-m73/test/functional/test_runner.py --jobs=4
work/build-m73/bin/mercatura-gpu-check --list
```

The renamed `mercatura_coinbase_template.py` preserves the former pool-coinbase
test's standard RPC/template, multi-output PQ reward, fees, maturity and independent
signing coverage. Only coordinator/transport-specific functional fixtures were
removed. GPU scheduling mocks now produce independent Solo jobs and retain CPU +
GPU, device failure, verification, cancellation, late-batch and restart coverage.

For a CPU-only build configure `WITH_OPENCL_MINING=OFF`. NVIDIA compilation
requires CUDA >=12 and `WITH_CUDA_MINING=ON`; preserve an explicit architecture
list with forward-compatible PTX. CI retains CPU/OpenCL and CUDA compile gates,
native Windows/macOS builds, walletless linkage, and static Qt packaging checks.

Hardware-free GPU checker exit code 77 is an intentional skip, not physical device
qualification. Outstanding live checks include NVIDIA/AMD vector parity,
GPU-only/combined sessions, multi-device scheduling, memory pressure, driver
failures and cancellation on supported cards. macOS/Windows/static packaging
CI definitions require their actual platforms.
