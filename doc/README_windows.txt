Mercatura Core
==============

Introduction
------------
Mercatura Core is the reference full-node and wallet software for the Mercatura
peer-to-peer digital currency network.

Mercatura Core validates the blockchain independently and can provide wallet,
network, and JSON-RPC functionality without relying on a trusted third party.


Setup
-----
Install or unpack Mercatura Core and run mercatura-qt.exe.

On first startup, Mercatura Core will synchronize with the Mercatura network.
Initial synchronization time depends on available CPU performance, storage,
network bandwidth, and the amount of blockchain history that must be processed.

The command-line node executable is mercaturad.exe and the JSON-RPC command-line
client is mercatura-cli.exe.
